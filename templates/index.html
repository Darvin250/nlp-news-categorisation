News Categorization is a web-based application developed using Flask that automatically classifies news articles as Real or Fake using Natural Language Processing (NLP) and machine learning techniques. The system preprocesses the input text by cleaning and standardizing it before converting it into numerical features using the TF-IDF method. A Logistic Regression model then analyzes these features to predict the authenticity of the news and displays both the classification result and a confidence score to the user. In addition to the news classification feature, the application includes a rule-based chatbot that assists users by answering common questions about the project, such as how the system works, the model used, and the accuracy achieved. The system runs on a local web server and can be accessed through a web browser, making it suitable for academic demonstration and learning purposes. This project demonstrates the integration of NLP, machine learning, and web development to create an interactive and user-friendly fake news detection system.
